## Executive Summary

This report presents the results of exploratory data analysis (EDA) and descriptive time-series analysis performed on the cleaned flight delay dataset prepared by Member 1B (`data/processed/flights_cleaned.csv`). The analysis verified data quality, confirmed target definitions, identified delay patterns across multiple dimensions, and examined temporal trends throughout 2015.

**Data Source:** Verified 2015 benchmark sample (24,522 operative flights). The full Kaggle dataset (5,714,008 flights) was not available locally; the benchmark was generated by `src/preprocessing.py::generate_diagnostic_flight_data()` with the same 31-column schema and operational characteristics.

> **Important:** Because the analysis uses a synthetic benchmark sample, absolute delay rates (~38.6%) differ from those in the full dataset (~17.9%). Relative patterns (e.g., time-of-day escalation) are structurally preserved. All findings should be re-verified on the full dataset when available.

## 6. Limitations and Data-Quality Issues

1. **Benchmark sample size (24,522 rows):** The analysis runs on a synthetic benchmark, not the full 5.7M dataset. Proportions and patterns may differ. All findings should be re-verified on the full dataset.
2. **Synthetic delay distribution:** The benchmark delay rate (~38.6%) is higher than the real rate (~17.9%) due to the synthetic data generator's delay parameters.
3. **Limited airport variety:** Only 15 airports are represented in the benchmark. The full dataset has 322 airports. The dual-coding issue (DOT numeric codes in Oct–Dec 2015) is not present in the benchmark.
4. **Uniform carrier sampling:** All 14 airlines are approximately equally represented in the benchmark (~1,700–1,800 flights each), whereas the full dataset has highly variable carrier volumes (Southwest alone has ~1.2M flights).
5. **TAIL_NUMBER missing values:** 65 entries (0.27%) are missing. This is an identifier column, not a primary modeling feature; the impact is minimal.
6. **SCHEDULED_TIME:** No missing values in the benchmark. The full dataset has 6 missing entries (negligible).
